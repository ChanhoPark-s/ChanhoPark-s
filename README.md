# 💼 Experience

## 대한약품공업 전산실
### WMS 개발 · 운영
**2023.01 ~ Present**

사내 물류시스템의 개발부터 운영까지 담당하며  
단순히 요청받은 기능을 구현하는 것을 넘어 **현업 물류 프로세스와 시스템의 연결 구조를 이해하는 것**을 중요하게 생각합니다.

### 담당 업무

- WMS 프론트엔드 및 백엔드 개발·운영
- Java / Spring 기반 업무 로직 개발 및 유지보수
- Nexacro 기반 사내 업무 화면 개발·개선
- Oracle DB / SQL을 활용한 데이터 조회 및 업무 로직 처리
- 입고·출고·재고 등 물류 프로세스 기반 시스템 운영
- 현업 요청사항 분석 및 시스템 개선
- 운영 장애 및 시스템 이슈 대응
- 배포 및 운영 환경 관리
- GitLab 기반 소스 형상관리
- GitLab Runner 및 CI/CD 환경 활용
- 기존 Eclipse 중심 환경에서 VS Code 활용 확대
- 업무 흐름 및 시스템 구성 문서화

### 물류 현장 시스템

- PDA 기반 물류 업무 시스템 경험
- PM85 / PM60 단말 사용
- Android Studio 기반 PDA 프로그램 확인 및 개발 경험
- 현장 사용자의 실제 작업 흐름을 바탕으로 시스템 이슈 분석

### 업무 방식

기능 하나만 개발하는 것보다

**현업 업무 → 화면 → 서버 로직 → DB → 배포 → 실제 사용자**

까지 이어지는 전체 흐름을 이해하려고 합니다.

운영 과정에서 문제가 발생했을 때도 단순 오류 수정으로 끝내기보다  
**왜 문제가 발생했는지, 같은 문제가 반복되지 않도록 어떤 구조를 바꿀 수 있는지**를 함께 고민합니다.

> 회사 내부 시스템 및 소스코드는 보안상 공개하지 않습니다.

# 🤝 Leadership & Collaboration

교육 과정과 프로젝트에서 반복적으로 조장·팀장 역할을 맡았고

- 행사 진행 순서 구성

# 🌱 What I Value

### 사용자 관점

시스템은 개발자가 사용하기 위한 것이 아니라  
**현업 사용자가 업무를 더 편하게 하기 위해 존재한다고 생각합니다.**

그래서 화면이나 기능을 개발할 때  
실제 사용자가 어떤 순서로 업무를 처리하는지를 먼저 이해하려고 합니다.

### 전체 흐름

프론트엔드, 백엔드, DB처럼 기술 영역을 나누는 것도 중요하지만  
업무시스템에서는 이들이 실제 업무와 어떻게 연결되는지가 더 중요하다고 생각합니다.

### 개선

이미 사용하는 방식이라고 해서 그대로 따르기보다  
더 효율적인 개발환경이나 운영 방법이 있다면 직접 확인하고 적용해보는 편입니다.
